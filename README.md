## 🐇 About me

Hey, I'm **jydzip**, a.k.a. the **Rabbit Knight**. 🌱

I'm learning software engineering at **Holberton School**, which means I spend a lot of time close to the machine: writing C, building a UNIX shell, re-implementing `printf`, and scripting in Bash. When I want to build something more visual, I switch to **TypeScript**, **React** and **three.js**.

I also work with communities and teams on GitHub as part of [**La-planque**](https://github.com/La-planque) and [**BrainNotFound-404**](https://github.com/BrainNotFound-404).
